/ MAPEAMENTO
Controles do PS2
Teclas: D-pad setas; analógico esquerdo T/F/G/H; analógico direito I/J/K/L; L1/L2/L3: 1/2/3; R1/R2/R3: 8/9/0; Start: Enter; Select: Backspace.
Preciso fornecer BIOS?
Não. O Play! utiliza uma implementação interna de alto nível; não carrega BIOS externa.
Por que alguns jogos não abrem?
A versão WebAssembly é experimental. Compatibilidade depende do jogo, do sistema, da GPU e do navegador. A versão desktop pode rodar títulos que a versão web não executa.
Funciona no iPhone?
A interface abre, mas o desempenho, a memória compartilhada, a compilação WebAssembly e os controles variam. Recomenda-se um desktop com Chrome ou Edge atualizado.
